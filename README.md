# PERIBACA — лендинг туров по Каппадокии

[![Лайв-демо](https://img.shields.io/badge/Live_demo-peribaca.vercel.app-1F3C8C?style=for-the-badge)](https://peribaca.vercel.app/)

Одностраничный сайт вымышленного туристического агентства: девять экранов, адаптивная вёрстка, ноль зависимостей. Проект вырос из учебного макета 2021 года — от него остались только идея и тема, весь код переписан заново.

## Дизайн

- **Палитра** — из фресок скальных церквей Гёреме: светлый туф, лазурь Токалы, базальт и охра. Тёплые фотографии лежат на холодном синем, а не тонут в бежевом.
- **Шрифты** — Sofia Sans Extra Condensed для заголовков (высокие узкие буквы, как сами «дымоходы фей») и Literata для текста.
- **Маршруты как разрез долины** — небо (+1000 м), дно долины (0 м) и подземный город (−85 м), сбоку шкала высот. Высота здесь — настоящее свойство маршрута, а не украшение.
- **Знак** — «дымоход феи», *peribacası*: столб туфа под базальтовой шляпкой, в честь которого названо агентство.
- **Рассвет** — на первом экране время завтрашнего восхода в Гёреме и час, когда заберут к полёту на шаре; считается в браузере.

## Технологии

- **HTML5 / CSS3** — CSS-переменные, grid, flex, `scroll-snap`, `clamp()`, `aspect-ratio`, `svh`
- **Vanilla JavaScript** — ~470 строк, без jQuery и фреймворков
- **WebP** — все фотографии, у первого экрана отдельные версии для десктопа и мобильных
- **Vercel** — статический хостинг

Из внешних ресурсов остались только Google Fonts. jQuery 3.6 (89 КБ ради одного `toggleClass`) и несжатый JPEG на 1,3 МБ из первой версии удалены.

## Что внутри

| Блок | Реализация |
|------|-----------|
| Первый экран | Фон через `<picture>` с раздельными кадрами под десктоп и мобильные, `preload` + `fetchpriority="high"`; время рассвета по формуле NOAA в часовом поясе Турции |
| Маршруты | Три яруса со шкалой высот и силуэтом скал на SVG; выбранный тур подставляется в форму через `data-service` |
| Программы | Таблица сравнения; на телефоне строки перестраиваются в сетку, роли ARIA сохраняют семантику |
| Регион | Коллаж с кадром в форме входа в пещеру и хронология от вулканов до наших дней |
| Кухня и ремёсла | Блок-фича и три колонки: блюда, мастерские, сезонные продукты |
| Галерея | Мозаика на CSS Grid без пустот + лайтбокс со стрелками и клавишами `←` `→` `Esc` |
| Отзывы | Карусель на `scroll-snap`: свайп, колесо и клавиши работают нативно, JS — только кнопки |
| Вопросы | Аккордеон на `aria-expanded`, открыт один ответ за раз |
| Заявка | Модальное окно с валидацией, focus-trap и honeypot против ботов |

## Доступность и производительность

- Кольцо фокуса на `:focus-visible`, skip-link, корректные `aria-expanded` / `aria-controls` / `aria-labelledby`
- Закрытое мобильное меню убрано из tab-order, модалка и лайтбокс удерживают фокус внутри и возвращают его при закрытии
- Единый источник блокировки прокрутки: меню, модалка и лайтбокс не перебивают состояние друг друга
- `Esc` закрывает ровно то, что открыто, — по приоритету лайтбокс → модалка → меню
- Контраст всех текстовых пар проверен и проходит WCAG AA (минимум для мелкого текста — 4,8:1; охра на синем — только крупным кеглем)
- Учитывается `prefers-reduced-motion`, hover-эффекты спрятаны за `(hover: hover)`
- Все `<img>` с явными `width`/`height` и `loading="lazy"` вне первого экрана — верстка не прыгает при загрузке
- Адаптив проверен на 320 / 360 / 480 / 600 / 768 / 900 / 1024 / 1440 / 1920 px, горизонтального переполнения нет
- Одна анимация при загрузке вместо появления каждого блока; без JS страница полностью читаема, строка с рассветом заменяется пояснением

## Форма заявки

Работает в демо-режиме: проходит валидацию, показывает подтверждение, но письмо не отправляет. Ключ почтового сервиса в публичном репозитории может использовать кто угодно, поэтому его здесь нет. Флаг `DEMO_MODE` в начале `js/main.js` и закомментированный `fetch` в `sendForm()` возвращают реальную отправку.

## Локальный запуск

Сборка не нужна — достаточно любого статического сервера:

```bash
python3 -m http.server 8000
```
